# データアナリスト ポートフォリオ

約7年間、人事・労務業務に従事してきました。
現在はデータアナリストへの転職を目指し、
SQL・BigQuery・Python・pandasを用いたデータ分析に取り組んでいます。

これまでの実務経験を活かしながら、
データから課題や傾向を捉え、
業務改善につながる分析ができるデータアナリストを目指しています。

## スキル

- SQL / BigQuery
- Python / pandas
- matplotlib
- Git / GitHub

## ポートフォリオ

### IBM HR 離職分析

従業員データを用いて、
離職と残業・職位・年齢などの関係を分析しました。

**使用技術：Python / pandas / matplotlib**

### Olist ECデータ分析

ブラジルのEC公開データ「Olist」を用いて、
売上・商品カテゴリ・地域などの観点から販売傾向を分析しました。

**使用技術：Python / pandas / matplotlib**

### Olist SQL分析

OlistのECデータをBigQueryに取り込み、
SQLによるデータ抽出・集計を行い、
売上・商品・顧客などの傾向を分析しました。

**使用技術：SQL / BigQuery**
